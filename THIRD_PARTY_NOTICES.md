# Third-party components

Runtime dependencies and exact versions are declared in `backend/pom.xml` and `frontend/package-lock.json`. They retain their upstream licenses. Spring components and the Maven Wrapper use Apache-2.0; React and Vite use MIT; PostgreSQL uses the PostgreSQL License; Lucide icons use ISC. Review the resolved dependency licenses before distributing a production build.

The v1 Mongoose pluralization implementation is no longer included in this codebase. Its original notice remains with the archived source.
